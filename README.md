# Nellis Fashion & Food Blog

Erste responsive Rohversion eines persönlichen Fashion- und Cooking-Blogs im eleganten Dark-Mode-Design.

## Lokal starten

```bash
npm install
npm run dev
```

Die aktuellen Bilder und Beiträge sind Platzhalter. Ein geschützter Redaktionsbereich für Uploads vom Handy wird in einer späteren Ausbaustufe ergänzt.
